# M02-D-003 — Executor e unidade de trabalho

Services controlam a unidade de trabalho e repositories recebem `Executor`, que pode
ser o database handle ou um transaction handle. O `TransactionManager` existente e
`withTenantTransaction` permanecem como implementação. Operações compostas compartilham
um único transaction handle; savepoint só é permitido quando a matriz declarar a
necessidade. Não há transação aninhada implícita.
