# M02-D-005 — Autoridade de cálculo e snapshots

Diagnóstico corrente é calculado server-side e a rota React apenas renderiza. Simulações
what-if usam módulo puro compartilhado e são recalculadas no servidor antes da
persistência. Snapshots são híbridos: não são gravados para cada leitura corrente,
mas são obrigatórios para histórico, exportação e simulação salva, incluindo inputs,
outputs, versões, política de arredondamento, moeda, timezone, período e proveniência.
