# M02-D-002 — Fronteira BFF e allowlist

Server functions de domínio não importam Drizzle, schema ou cliente de banco, inclusive
transitivamente. A allowlist de acesso direto contém somente health/readiness,
auth/membership, rate-limit e migrations/scripts. Clientes externos de IA podem fazer
I/O externo, mas sua persistência é obrigada a passar por services/repositories.
