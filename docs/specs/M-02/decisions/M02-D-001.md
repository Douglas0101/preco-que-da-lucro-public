# M02-D-001 — Autoridade do catálogo e precedência

O catálogo de services/repositories para M-02 é o conjunto convergente do Plano Mestre,
da Arquitetura Consolidada e da Diretriz V7. `SDD.md` é normativo para contratos de
domínio, mas seu catálogo divergente é derivado até ser reconciliado por mudança
documental explícita. Esta decisão usa identificador próprio para não colidir com
ADR-001..005 existentes.
